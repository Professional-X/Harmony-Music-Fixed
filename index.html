What is Harmony Music?

Harmony Music is a popular cross-platform music streaming app built with Flutter (3,000+ GitHub stars) that lets you play music from YouTube and YouTube Music. It features background playback, playlists, equalizer, synced lyrics, Android Auto support, and more — all without ads or login requirements.

The original Harmony Music project by anandnet is no longer maintained, which caused harmony music not working issues for thousands of users worldwide. The search functionality broke due to YouTube and Piped API changes, and the app started crashing on newer Android versions. This community fork provides the harmony music update that users need — with fixes for search, playback, and stability, plus new Windows and upcoming Linux desktop support.

Why This Fork?

If you're wondering "what happened to Harmony Music", the answer is straightforward: the original GitHub repository by anandnet stopped receiving updates, leaving thousands of users without a working music app. This fork was created to keep Harmony Music alive and bring it to more platforms.

Beyond fixing bugs, we've expanded Harmony Music to Windows (available now as a native desktop app) and are actively developing the Linux version. Every release addresses real user-reported issues, and the full source code is transparent on GitHub under GPL v3.0.

Users from India, Malaysia, Spain, France, Indonesia, Brazil, Germany, and beyond rely on this fork for a working, ad-free music streaming experience on Windows, Android, and soon Linux.

What is Harmony Music?

Why is Harmony Music search not working in the original app?

The original Harmony Music app is no longer maintained. YouTube and Piped API endpoints changed, breaking search functionality. This fork updates those endpoints and patches compatibility so search works on all platforms.

What happened to the original Harmony Music?

The original Harmony Music by anandnet is abandoned — no updates, broken search, playback failures, and crashes. This fork continues maintenance, adds Windows support, and is developing Linux support.

Is Harmony Music a good YouTube Music alternative?

Yes. Harmony Music streams from YouTube Music but without ads, without login, and with extra features like equalizer, synced lyrics, offline downloads, and Android Auto. If YouTube Music crashes on your device, Harmony Music is a stable, feature-rich alternative.

Is Harmony Music safe to install?

Does Harmony Music have a desktop app?

Yes! The Windows desktop app is available now with a full-featured UI, background playback, playlists, equalizer, and more. A Linux desktop app is in active development and will be released soon.

What platforms does Harmony Music support?
