## ℹ️ About

This is a **community-fixed fork** of [Harmony Music](https://github.com/anandnet/Harmony-Music) by [anandnet](https://github.com/anandnet) (3,000+ GitHub stars). The original project is a cross-platform music streaming app built with **Flutter**.

Since the original is no longer maintained, this fork keeps the app functional by fixing critical bugs and compatibility issues with current YouTube/Piped backends and newer Android versions. We've also expanded platform support — **Windows is now available as a native desktop app**, and **Linux is in active development**.

Users from India, Malaysia, Spain, France, Indonesia, Brazil, Germany, the United States, and beyond rely on this fork for a working, ad-free music streaming experience across **Windows, Android, and soon Linux**.

Harmony Music is one of the best free alternatives to YouTube Music — offering the same music library with no ads, no subscriptions, and extra features like equalizer, synced lyrics, and offline downloads.

## ❓ FAQ

**What is Harmony Music?**
Harmony Music is a free, open-source, cross-platform music streaming app that plays music from YouTube and YouTube Music. It features background playback, playlists, equalizer, synced lyrics, Android Auto, and zero ads. Built with Flutter, it now supports **Windows** (available), **Android** (available), and **Linux** (in development).

**Is Harmony Music available for Windows?**
Yes! **Harmony Music for Windows is available now.** Download the Windows installer from [harmonyfixed.space-z.ai](https://harmonyfixed.space-z.ai/). Supports Windows 10 and Windows 11 with full features including background playback, playlists, equalizer, and a native desktop UI.

**Is Harmony Music available for Linux?**
The Linux version is **in active development**. It will support Ubuntu, Fedora, Debian, Arch, and more with multiple package formats (.deb, .rpm, AppImage, AUR). Follow this repo for updates.

**Why is Harmony Music search not working?**
The original app is unmaintained. YouTube and Piped API endpoints changed, breaking search. This fork updates those endpoints and patches compatibility so search works again on all platforms.

**What happened to Harmony Music?**
The original repo by anandnet is abandoned — no updates, broken search, playback failures, and crashes. This fork continues maintenance with regular updates, Windows desktop support, and upcoming Linux support.

**Where can I download Harmony Music?**
Download from [harmonyfixed.space-z.ai](https://harmonyfixed.space-z.ai/) or the [GitHub Releases](https://github.com/Professional-X/Harmony-Music-Fixed/releases) page. Available for **Windows** (installer) and **Android** (APK).

**Is Harmony Music free?**
Yes, **completely free**. Open-source under GPL v3.0. No ads, no premium tiers, no subscriptions, no login required. It is and will always be free.

**Is Harmony Music safe to install?**
Yes. The full source code is transparent on GitHub under GPL v3.0. You can review the code, build it yourself, or download the pre-built releases. No hidden trackers, no data collection.

**Does it fix YouTube Music crashes on Android?**
If YouTube Music crashes on Android, Harmony Music is a stable open-source alternative with background playback, playlists, equalizer, synced lyrics, and no ads. The latest update ensures full Android 13/14 compatibility.

**Does Harmony Music have a desktop app?**
Yes! The **Windows desktop app is available now** with a full-featured UI. A **Linux desktop app** is in active development.

**What platforms does Harmony Music support?**
Harmony Music is cross-platform: **Windows** (available now), **Android** (available with all fixes), and **Linux** (in development). macOS support may come in future updates based on community demand.

**Is this a good YouTube Music alternative?**
Yes. Harmony Music streams from YouTube Music but **without ads, without login**, and with extra features like equalizer, synced lyrics, offline downloads, and Android Auto. It's one of the best free YouTube Music alternatives available.
